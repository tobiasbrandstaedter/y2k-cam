Environment: Chrome in the embedded browser pane of the Claude desktop app, Windows 11, device pixel ratio 1. Not tested on iOS Safari (see `CLAUDE.md`, Verification environment). All numbers below are desktop numbers and say nothing about the iPhone targets.

Test photos: `docs/looks/references/user-reference-01-camcorder-digicam.png` (447 x 447 portrait collage, skin tones) and `spikes/testmedia/Image.jpg` (4032 x 3024 interior, local only). Before and after were rendered side by side from a copy of the previous `src/` in the same page.

## Parameter harness

Every parameter of every effect, rendered at default and changed (range moved by half its span, other select option, toggle flipped, text changed), with prerequisites set where a parameter only acts together with another (split saturations, tracking amount, a status line for its position). 129 variants at 320 x 320.

- 125 change the image at 320 x 320.
- 4 do not, all expected: scanline density and variation, interlace lines (moire guard below 2 to 3 px per line) and vignette roundness (only matters for non-square images). All 4 change the image at 1600 x 1200.

## Not verified

- iOS Safari 17: everything above. The new code uses only GLSL ES 3.00 features already used before (`textureLod`, `textureSize` and integer hashes are core WebGL2), no extensions. Shader length grew; compile time on the phone is unmeasured.
- The extra texture reads (17 luma taps for Band-Auflösung, 8 for Purple Fringing) are cheap on desktop; on a phone at 12 MP they are the first place to look if export gets slow.

## Open points for the user

- Reference 3 shows dark translucent boxes behind `REC` and the counter, and rounded frame corners. Not built; both would be new overlay options.
- A burned in camcorder date stays sharper than the tape blurred picture, because overlays are composited after the signal pass.
- Sepia Light, Gaussian Blur, Motion Blur, Lens Blur and Lens Flare are still unused by presets on purpose (see `docs/looks/film.md`).
